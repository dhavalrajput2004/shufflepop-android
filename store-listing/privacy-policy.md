# ShufflePop Privacy Policy

**Effective date:** 10 October 2026

ShufflePop is published by Dhaval Rajput.

The current ShufflePop solo application works offline and does not collect, transmit, sell, or share personal information. It contains no advertising, analytics, user accounts, purchases, or network permission.

The application stores the current game and solo win count locally on the user's device. Android cloud backup is disabled. This local data can be removed by using the in-app deletion option, clearing the application's storage, or uninstalling the application.

Future online multiplayer functionality will require an updated privacy policy before release. This policy must not be used to describe an online-enabled version without review.

For support, use the developer contact address displayed on the application's Google Play listing.
