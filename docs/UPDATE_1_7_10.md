# ShufflePop! 1.7.10

The global solo wins popup shows standings, your profile and a Done button. Removed the ranked/offline toggle and extra introductory copy. Joining remains available for players without a leaderboard profile.

New solo rounds automatically use global scoring for joined profiles, including profiles previously switched to offline. Existing rounds keep their original scoring status. Connection failures still allow local play.

Android version code: 29.
