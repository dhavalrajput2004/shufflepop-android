# ShufflePop! 1.7.9

- New solo games start directly from Home and Game settings.
- Ranked connection progress stays on the start button; connection failure starts an offline round without an extra dialog.
- Home shows device-local solo wins and verified global solo wins separately. Local wins are never imported into global standings.
- Expired leaderboard profiles return to the join form with the previous nickname prefilled. Solo saves and local wins remain intact.
- Cloud requests allow enough time for the free server to wake.

Android version code: 28. Cloud leaderboard uses the existing Render endpoint with Neon storage; the PC tunnel is no longer required.
